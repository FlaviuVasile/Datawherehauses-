# Demo Checklist

Use this flow for the required short demo video.

1. Start MongoDB and the Spring Boot app.
2. Open `http://localhost:8080`.
3. Click `0. Seed Local Demo Data`.
4. Run Q1 list assets.
5. Run Q2 asset details for `AAPL`.
6. Run Q3 list providers.
7. Run Q4 provider details for `DEMO_VENDOR`.
8. Run Q5 time series for `AAPL` and `DEMO_VENDOR`.
9. Run analytics summary.
10. Run forecast next day.
11. Run assistant tools.
12. Run assistant summarize, forecast, and explain change.
13. Run temporal update asset.
14. Run asset history and show the old and new versions.
15. Optional: run the MCP server and call the same platform capabilities through MCP tools.
